# tattvaCo — AI-Native Film Development & Production OS

> **Turning Ideas into Impactful Stories**  
> An AI-native operating system for film development and production management, unifying narrative ideation, screenplay formatting, continuity QA, and greenlight delivery into a single connected project intelligence.

---

## 🎬 Guiding Philosophy

> *"tattvaCo is not 17 disconnected pages. There is ONE Project underneath the 17 pages."*  
> **Explore → Propose → Decide → Approve → Remember → Propagate**

Every stage of the narrative and production pipeline shares a single, reactive, canonical project memory. Modifying foundational elements in one department immediately cascades intelligent downstream impact assessments across characters, scene structures, dialogues, visual assets, casting profiles, and production budgets.

---

## 🚀 Key Highlights & Flagship Features

### 1. Downstream Change Impact Analysis Engine
- **Core Trigger**: Modifying protagonist Aanya Verma’s age from **24 to 34** on the Character Development board.
- **Intelligent Cascade**: tattvaCo intercepts the change and surfaces **12 affected objects** across **6 categories**:
  - **Characters**: Psychosocial transition from student idealism to seasoned urgency and systemic burnout.
  - **Story**: UPSC eligibility deadline pressure and adult confrontation with father over 10 lost years.
  - **Scenes**: Scene 1 set dressing updates from textbooks to a decade of dog-eared notes and father's medicine; Scene 3 dining room subtext deepens.
  - **Dialogue**: Monologue gains decade-long gravitas (*"Ten years ago I thought time was on my side..."*); Mother's O.S. interaction shifts to age anxiety.
  - **Visuals**: Lookbook shifts to muted earth tones; color grade desaturates to cool monsoon contrast.
  - **Production**: Casting brief age bracket updates from 22–25 to 30–36 (e.g., Radhika Apte / Tillotama Shome archetype).
- **Interactive Review**: Review individual diffs, approve selectively, and propagate changes across the entire project with celebratory confetti feedback.

### 2. 16-Stage End-to-End Pipeline
1. **Create Project**: Metadata, distribution format, genre chips, and AI poster generator.
2. **Project Intake**: Natural language concept ingestion, "Analyze with AI", and gap checklist.
3. **Research & Evidence**: Verified findings, primary source badges, confidence meters, and entity mapping.
4. **Story Exploration**: Direction cards A, B, C with loglines, narrative engines, and interactive Direction Combiner.
5. **Format & Template**: Feature Film vs Series recommendations, deep AI rationale breakdown, and structural rhythm templates.
6. **Character Development**: Deep psychometrics (*want, need, fear, flaw*), relationship tension graph, and Change Impact Engine.
7. **Story World & Setting**: Contemporary India setting, interactive SVG contour map with location pins, and production rigging notes.
8. **Story Structure**: Dynamic 0–125 min timeline bar with cardinal beats, 3-act columns, and tension curve optimizer.
9. **Narrative Treatment**: 14,800-word prose treatment viewer/editor, visual moodboard insets, and 12-plot-beat board.
10. **Scene Outline**: 32 scenes grouped by acts, deep inspection of Scene 1, ambient monsoon audio player, and scene insights radar.
11. **Screenplay Editor**: Industry-standard **Courier Prime** Hollywood screenplay draft (118 pages), element formatting toolbar, and **AI Subtext Punch-Up**.
12. **Dialogue Studio**: Audio waveform visualizer, urgency/subtext cadence meters, and multi-register AI dialogue variations with **"Use This In Screenplay"** live hot-swapping.
13. **Continuity & QA Auditor**: Side-by-side shot comparison demonstrating prop detection (*Scene 1 lantern vs Scene 2 missing lantern*) and **"Apply Automated Script Fix"**.
14. **Visual Development**: 6-tone cinematographic color palette swatches, Keyframes KF-01 to KF-04 gallery, and supervising art director notes.
15. **Production Planning**: 6 KPI cards, interactive multi-phase Gantt timeline, ₹38.5 Cr budget allocation progress bars, and risk registry.
16. **Package Delivery & Greenlight**: 14-item master verification checklist, deliverable asset cards with download simulation, executive sign-off chain, and **"Submit for Official Studio Greenlight"** action.

### 3. Contextual Film Intelligence Copilot
- Right slide-over drawer accessible from any screen providing contextual recommendations, quick prompt actions, and greenlight readiness metrics.

### 4. Figma Design Spec Comparison Overlay
- Floating bottom-left toolbar featuring instant jumping to all 17 screens and a **"Compare Page XX Design"** modal overlay to view the original high-resolution design side-by-side.

## 📦 Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm or pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/Kaustubhd0022/DVS-V1-.git

# Navigate into the project directory
cd DVS-V1-

# Install dependencies
npm install

# Start the local development server
npm run dev
```

Visit `http://localhost:5173/` in your browser.

### Building for Production

```bash
npm run build
```
